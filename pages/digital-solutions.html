Practical Tools and Low-Code Solutions

Rapid, Low-Cost Tooling

  • built decision-tree interfaces in MS Excel that behaved like web pages
  • developed the KSP ASAP tool in MS Excel to streamline call-center workflows with a hidden worksheet tab that the call center supervisors can update to get just-in-time information for the call center agents
  • created ticket intake workflows using MS Planner (without extra licensing to purchase Kanban Boards); included assignments, due dates, status updates, reporting features, attachments (to enhance version control without using emails to send revisions), and online instructions embedded into the cards
  • designed solutions minimizing developer time for small fixes (context menus, UI tweaks)

Requirements, Triage and Handoff

  • acted as application analyst between users and developers for clear requirements
  • determined whether requests were quick fixes or needed full spec/use-case work
  • produced lightweight specs to speed developer handoffs when needed
  • implemented solutions that avoided unnecessary developer cycles

Operational Examples and Outcomes

Call Center Efficiency

  • reduced agent steps by guiding responses through 4-question flows which improved call quality and minimized agents having to learn various if/then statements for a complicated workflow
  • allowed supervisors to update answers via a hidden Excel tab (no developer required)
  • improved speed to resolution and reduced training time for agents
  • enabled immediate content updates without purchasing new tools

Governance and Practical Trade-Offs

  • evaluated whether issues were FADs (functions as designed) or WADs (works as designed)
  • balanced quick wins (context menus) against larger Enhancement Requests (EHR) for new features
  • worked with Compliance and Ops to reduce risk and preserve usability
  • scaled simple solutions across teams to improve KPIs and minimize development cost
